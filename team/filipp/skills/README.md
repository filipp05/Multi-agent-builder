# Навыки участника: Филипп

Здесь можно хранить инструкции помощнику для своей части проекта: отдельная папка на навык, внутри `SKILL.md`. Доступен [codex-exec-brief](codex-exec-brief/SKILL.md): зачем прорабу Codex exec, запуск по подписке, проверка ответов и диагностика.

В инструкции опиши: когда применять, какие данные читать, что выдавать и как проверить результат. Ссылайся на [общие контракты](../../../contracts/README.md), не копируй их. Файлы в этой папке сами по себе не подключаются к помощнику: способ установки зависит от используемого инструмента.

Чтобы применить навык в текущем чате, укажи путь `team/filipp/skills/codex-exec-brief/SKILL.md` и попроси следовать ему. Этот каталог хранит навык в Git; автоматическое обнаружение помощником здесь не предполагается.
