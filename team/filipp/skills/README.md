# Навыки участника: Филипп

Здесь можно хранить инструкции помощнику для своей части проекта: отдельная папка на навык, внутри `SKILL.md`. Готовых навыков здесь пока нет.

В инструкции опиши: когда применять, какие данные читать, что выдавать и как проверить результат. Ссылайся на [общие контракты](../../../contracts/README.md), не копируй их. Файлы в этой папке сами по себе не подключаются к помощнику: способ установки зависит от используемого инструмента.
