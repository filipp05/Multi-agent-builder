# Попробовать MVP на своём компьютере

Есть браузерный интерфейс: `/` — пожелания и подтверждение брифа, `/plan` — две концепции, выбор и полный расчёт. `/oleg/` и `/karina/` — отдельные учебные страницы модулей. Swagger: `/docs`.

## Подготовка

Python 3.12, Codex CLI с входом через ChatGPT; команды из корня репозитория:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-app.txt
codex login status
# Если ещё нет входа:
codex login
```

## Через подписку ChatGPT

```bash
.venv/bin/python scripts/run_mvp.py --provider codex
```

Открыть http://127.0.0.1:8000. Это `codex exec`, а не `codex.exe`: отдельный неинтерактивный процесс на каждый LLM-вызов. Модель удалённая, расходуются лимиты Codex аккаунта. API-ключ OpenAI не нужен. Учётные данные Codex остаются на ноутбуке, серверу не передаются.

Опционально:

```bash
.venv/bin/python scripts/run_mvp.py --provider codex --model gpt-6-astra --port 8001
```

Провайдер выбирается при запуске. Остановить Ctrl+C, затем запустить с другим `--provider`. `--model` меняет модель выбранного провайдера, а не провайдера. Список поддержанных вариантов: `--help`.

## Через AWS Bedrock

В том же терминале предварительно задать `AWS_BEARER_TOKEN_BEDROCK` приватно и `AWS_REGION=us-east-2`:

```bash
.venv/bin/python scripts/run_mvp.py --provider bedrock --model amazon.nova-lite-v1:0
```

С нулевой квотой AWS это не заработает даже при $100 кредитов. Short-term ключ нужно обновлять после истечения. Для другой модели Bedrock потребуются её корректный model/inference-profile ID, поддержка Converse и явные ставки `MODEL_INPUT_USD_PER_MILLION` / `MODEL_OUTPUT_USD_PER_MILLION` вне встроенного списка.

Сейчас подключены **только Codex и Bedrock**. Прямые OpenAI API, OpenRouter, Together и локальный Ollama не являются доступными значениями `--provider` этой сборки; для них нужен отдельный адаптер.

Эквивалент без launcher:

```bash
MODEL_PROVIDER=codex CODEX_MODEL_ID=gpt-6-astra RENOVATION_DATA_DIR=.scratch/local-mvp \
  .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## Что ввести

«Хочу покрасить стены и уложить ламинат в сухой комнате 5×4 м, высота 2,7 м, проёмы 3 м². Основание подготовлено. Бюджет 200 000 ₽, Москва. Начать 1 ноября 2026, закончить до 1 декабря 2026. Одна бригада, пн–пт, с 9:00 по 8 часов. Обязательных дополнительных требований нет».

Проверьте сводку и подтвердите её, затем перейдите на `/plan`, получите две концепции и выберите одну. После брифа ожидаются пять вызовов LLM; повторы и уточнения могут увеличить число. Первая проверка нужна для работоспособности, она не доказывает качество на всём наборе запросов.

Данные сохраняются в `.scratch/local-mvp` и исключены из Git. Смена провайдера их не удаляет. Для отдельного набора проектов используйте `--data-dir .scratch/local-mvp/experiment-1`. Пароль для localhost не нужен; сервис слушает только loopback. Закрытый сервер с командным паролем — отдельное окружение.

Ограничения: учебные цены/нормы/каталог, одна комната, текстовые концепции; без генерации картинок и 3D. Неподтверждённые условия и ошибки моделей показываются явно.

[Официальная документация codex exec](https://learn.chatgpt.com/docs/non-interactive-mode).

## Проверка 23 октября 2026

На macOS, Python 3.12 и Codex CLI 0.162.0 с ChatGPT выполнены живой smoke и один полный проход через `gpt-6-astra`. Получены все восемь документов. Конечный статус `constraints_unresolved`: смысловой контролёр отметил отсутствие подтверждения оттенков выбранных товаров и раскрытого состава расходников/комплекта подготовки. Эти замечания сохранены, а не заменены успешной заглушкой. Это один рабочий пример, не массовая оценка качества.
