# 02: Закупки и смета

**Что сделать:** Из состава работ пользователь получает корзину упаковок и смету с источниками и сравнением с бюджетом.

**Зависит от задач:** Нет — можно начинать на общем примере.

**Статус:** ready-for-agent

**Ответственный:** Олег. Уточняет существующие задачи 03, 06, не добавляет отдельный объём или баллы. Нумерация зависимостей здесь относится только к этому плану стыковки.

- [ ] Упаковки округляются вверх, доставка учитывается один раз на поставщика.
- [ ] Материалы, работа, доставка и резерв показаны отдельно.
- [ ] Контрольный пример даёт 74 250 рублей; неизвестная доставка не считается нулём.
- [ ] Свои обработчики подключены к общему интерфейсу и проверены на правильных и неправильных данных.
- [ ] Свой результат показан в минимальном пользовательском интерфейсе.
- [ ] Приложены вход, выход, команда проверки и оставшиеся ограничения.
