# 04: Общий пользовательский путь

**Что сделать:** Пользователь вводит запрос, выбирает концепцию, получает проверенный комплект и пересчитывает его при смене бюджета.

**Зависит от задач:** 01, 02, 03 — для завершения интеграции. Ввод, выбор, хранение и вызов этапов можно делать сразу.

**Статус:** ready-for-agent

**Ответственный:** Филипп. Уточняет существующие задачи 01, 08, не добавляет отдельный объём или баллы. Нумерация зависимостей здесь относится только к этому плану стыковки.

- [ ] Есть настоящий вызов модели; готовые примеры не подменяют его на защите.
- [ ] Смена бюджета создаёт новый запуск и ревизию; старый ответ отвергается.
- [ ] Вопрос, ошибка и нарушение ограничений не превращаются в успешный результат.
- [ ] Проверены пределы повторов и запуск приложения по инструкции.
- [ ] Свои обработчики подключены к общему интерфейсу и проверены на правильных и неправильных данных.
- [ ] Свой результат показан в минимальном пользовательском интерфейсе.
- [ ] Приложены вход, выход, команда проверки и оставшиеся ограничения.
