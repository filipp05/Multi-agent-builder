# Исторические материалы

Здесь сохранены прежние проектные исследования, варианты спецификаций и задания стыковки. Они перенесены из отслеживаемой `.scratch`, чтобы временные данные не смешивались с документацией.

**Это не актуальный статус реализации и не автоматически утверждённый backlog.** Даты, сроки, владельцы, число отдельных LLM и планы 01–24 внутри документов могут относиться к прежним предложениям. Новые обязательства принимает команда; состояние продукта описывают [README](../../README.md) и [архитектура](../architecture.md).

- [Первоначальный пакет проекта](renovation-mvp/).
- [История согласования контрактов](shared-contracts/).

Содержимое сохранено как история; локальные ссылки адаптированы к новым путям. Некоторые ссылки на внешние материалы курса или прежние локальные результаты недоступны из публичного репозитория; архив не является инструкцией запуска.
