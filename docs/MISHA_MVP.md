# B: концепции, технология и общий план

Реализация для проверки командой, 23 октября 2026. Общие контракты 0.1.0 сохранены. Старые SPEC/TEAM_PLAN не становятся утверждёнными этой реализацией.

## Пользовательский сценарий

1. На `/` пользователь вводит пожелания, отвечает на вопросы и подтверждает бриф Филиппа.
2. На `/plan` выбирает проект и получает две текстовые концепции.
3. Выбирает концепцию. Технолог считает работы и потребность; Олег выбирает товары и считает смету; Карина строит календарь и проводит программный и смысловой аудит.
4. Видит восемь документов, итоговый статус и может скачать JSON. `completed` означает прохождение проверок, а не пригодность для реального строительства.

Промежуточные результаты сохраняются. Выбор другой концепции создаёт новую ревизию; история доступна через `GET /api/projects/{id}/plan/history`. Изменение брифа делает прежний результат устаревшим. Повтор одинакового `action_id` не запускает второй расчёт.

## Границы и правила

Одна прямоугольная сухая комната, покраска и ламинат, одна бригада. До 60 м² стен и 25 м² пола: это границы учебных фиксированных тарифов. Неподтверждённое основание оставляет статус `constraints_unresolved`. Электрика, сантехника, перепланировка, изображения и 3D не реализованы.

| Параметр | calm | accent |
|---|---|---|
| Укладка | Прямая | Диагональная |
| Запас ламината | 10% | 15% |
| Работа по полу | 8 часов | 12 часов |

Общие учебные нормы: площадь стен `2×(длина+ширина)×высота−проёмы`; краска 0.2 л/м² суммарно на два слоя, запас 10%; лёгкая подготовка 8 часов; окраска 8 часов с 16 часами ожидания. Источник `misha-tech-v1` явно имеет тип `synthetic`. Каталог, цены и тарифы также учебные.

LLM формулирует концепции, выбирает только из разрешённых кандидатов и объясняет результат. Геометрию, упаковки, суммы, календарь и инварианты считает код. Независимый контролёр Карины пересчитывает показатели; признание `misha-tech-v1` допустимым источником не отключает проверку чисел. Есть тест подмены расхода краски.

## Код и интерфейсы

- `app/misha/stages.py`: дизайн, выбор и детерминированный план работ через `StageContext` / `StageResult`.
- `app/pipeline.py`: последовательность A→B→C→D, подтверждение выбора, ревизии, остановка и сохранение состояния в SQLite.
- `app/providers/bedrock.py`: общий адаптер `ModelRequest → ModelReply` через Bedrock Converse, строгая проверка JSON и схемы.
- `app/main.py`: единый FastAPI, исходные страницы A/C/D и общий `/plan`.

После подтверждённого брифа выполняется пять вызовов модели: дизайн, выбор товаров, объяснение сметы, объяснение календаря, смысловой аудит. При невалидном JSON Bedrock-адаптер допускает одну повторную попытку; ошибки доступа/квот не повторяет. Технолог отдельной LLM не требует. Число вызовов разбора брифа зависит от уточнений.

Один процесс/worker, один выполняющийся общий план, один одновременно выполняющийся вызов Bedrock для всех ролей. Общий план ограничен восемью минутами. После перезапуска активные расчёты становятся `interrupted`, без автоматического платного повтора. Подход рассчитан на закрытую команду из четырёх человек, а не на публичный сервис.

## Модель и расходы

Nova Lite v1 в Ohio выбрана только как дешёвый первый smoke-test. Это не итоговый выбор качества: живые вызовы 23 октября получили ограничение суточной квоты; успешный ответ не подтверждён. Тестовые ответы явно находятся только в тестах, приложение не подменяет ими ошибки AWS.

Кандидат для проверки качества дизайнера и смыслового контролёра — актуальная Claude Sonnet. Подключение другой модели требует проверки доступности, параметров Converse, цены, покрытия кредитами и отдельного прогона evaluation. Пока одна модель используется всеми ролями; автоматического переключения и смешанного маршрута нет.

Локальный лимит `MODEL_BUDGET_USD` по умолчанию $5. Это консервативный счётчик оценок, не банковский лимит AWS: резервируется объём до запроса, успешные ответы пересчитываются по usage; неоднозначные ошибки оставляют резерв. Данные хранятся в `usage.sqlite3` и переживают перезапуск. Кэш, точные правила биллинга и изменения тарифов могут отличаться от оценки. Не удаляйте файл ради сброса лимита.
