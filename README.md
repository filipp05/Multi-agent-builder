# Ремонт под контролем — план проекта

Мультиагентный помощник превращает пожелания к ремонту в согласованные дизайн-концепцию, состав работ, смету, список покупок и календарный план. При конфликте бюджета и сроков показывает компромиссы и пересчитывает затронутые решения.

**Состояние на 20 октября 2026:** подготовлены план, общие контракты, примеры и автоматические проверки. Приложение ещё предстоит реализовать. Команда: Филипп (A), Миша (B), Олег (C), Карина (D).
