# Ремонт под контролем — план проекта

Мультиагентный помощник превращает пожелания к ремонту в согласованные дизайн-концепцию, состав работ, смету, список покупок и календарный план. При конфликте бюджета и сроков показывает компромиссы и пересчитывает затронутые решения.

**Состояние на 23 октября 2026:** собран сквозной MVP: бриф Филиппа (A), две концепции и технология Миши (B), закупки/смета Олега (C), график/аудит Карины (D). Общая страница `/plan`, SQLite и Bedrock-адаптер. Каталог и нормы учебные; изображения и 3D пока отсутствуют. Живой прогон Bedrock заблокирован нулевой суточной квотой аккаунта. Локальный сквозной прогон через Codex выполнен: восемь документов, с замечаниями смыслового аудитора к полноте каталога.
